== Description ==

**Bangla QR** is an automated payment gateway plugin for the PipraPay open source project, allowing merchants to accept payments from all Bangladeshi banks and Mobile Financial Services (MFS) via the interoperable Bangla QR standard.

**Key Features:**
* Interoperable payment support (bKash, Nagad, Rocket, Upay, Cellfin, BRAC Astha, City Touch, NexusPay, Tap, etc.)
* Custom Bangla QR image direct upload from Admin Panel.
* Built-in 15-minute countdown timer with real-time expiration handling.
* 100% Automatic real-time background payment verification via SMS notifications.
* Instant Telegram bot notification and IPN webhook triggering upon payment.
* One-click QR image download for mobile customers to scan directly from gallery.
* Fully responsive and modern checkout user interface.
